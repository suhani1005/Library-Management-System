# Library Management System

## Project Overview
The Library Management System is a web-based application developed to manage library books and user activities. It helps in organizing and managing book records efficiently.

## Technologies Used
- Java
- Java Servlets
- JSP
- HTML
- CSS
- JavaScript
- MySQL
- Apache Tomcat
- NetBeans IDE
- Maven

## Features
- User Registration and Login
- Add Books
- View Books
- Edit Book Details
- Delete Books
- MySQL Database Connectivity

## Tools Used
- NetBeans IDE
- Apache Tomcat Server
- MySQL Workbench
